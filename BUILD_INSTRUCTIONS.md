# Інструкція зі збірки та запуску

## Спосіб 1: Android Studio (найпростіше)

1. Завантажте та встановіть [Android Studio](https://developer.android.com/studio)
2. Клонуйте репозиторій:
   ```bash
   git clone https://github.com/Netyura/TestYura.git
   cd TestYura
   git checkout claude/angry-birds-android-game-01UQshGga25DsgaysfipA62a
   ```
3. Відкрийте проект в Android Studio
4. Дочекайтеся синхронізації Gradle (автоматично завантажить залежності)
5. Створіть віртуальний пристрій (AVD):
   - Tools → Device Manager → Create Device
   - Виберіть Pixel 5 або інший пристрій
   - Завантажте Android 11+ system image
6. Натисніть Run (зелений трикутник) або Shift+F10

## Спосіб 2: Збірка через командний рядок

### Потрібні компоненти:
- Android SDK
- Java 8 або вище

### Збірка:
```bash
# Зробіть gradlew виконуваним (Linux/Mac)
chmod +x gradlew

# Зберіть debug APK
./gradlew assembleDebug

# APK буде в: app/build/outputs/apk/debug/app-debug.apk
```

### Встановлення на пристрій:
```bash
# Підключіть Android пристрій через USB (увімкніть USB debugging)
./gradlew installDebug

# Або встановіть APK вручну
adb install app/build/outputs/apk/debug/app-debug.apk
```

## Спосіб 3: Встановлення APK файлу на телефон

1. Зберіть APK (дивіться вище)
2. Скопіюйте `app-debug.apk` на телефон
3. На телефоні:
   - Налаштування → Безпека → Дозволити встановлення з невідомих джерел
   - Відкрийте файловий менеджер
   - Знайдіть та натисніть на APK файл
   - Натисніть "Встановити"

## Системні вимоги

- **Мінімальна версія Android**: 5.0 (API 21)
- **Рекомендована версія**: Android 11+ (API 30+)
- **Орієнтація**: Краще грати в ландшафтному режимі (горизонтально)

## Керування грою

- **Перетягніть** птаха на рогатці назад
- **Відпустіть**, щоб запустити
- **Мета**: знищити всіх зелених свинок

## Проблеми та рішення

### Gradle sync failed
- Переконайтеся, що встановлено Android SDK
- Перевірте інтернет-з'єднання (для завантаження залежностей)
- File → Invalidate Caches → Invalidate and Restart

### Емулятор не запускається
- Перевірте, що HAXM/KVM увімкнено (для прискорення)
- Виділіть більше RAM для емулятора (рекомендовано 2GB+)

### Гра лагає
- Спробуйте зменшити розмір екрану емулятора
- Використовуйте фізичний пристрій для кращої продуктивності
