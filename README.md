# Angry Birds - Android Game

Це базова реалізація гри Angry Birds для Android.

## Особливості

- 🎮 Класична механіка гри Angry Birds
- 🐦 Три різнокольорові птахи
- 🐷 Зелені свинки як цілі
- 🧱 Дерев'яні блоки для створення конструкцій
- ⚙️ Реалістична фізика (гравітація, зіткнення, відскок)
- 🎯 Рогатка для запуску птахів
- 📊 Відображення рахунку та залишку птахів

## Як грати

1. Перетягніть птаха на рогатці назад
2. Відпустіть, щоб запустити птаха
3. Знищіть всіх свинок, щоб виграти рівень
4. Використовуйте якомога менше птахів для кращого результату

## Технічні деталі

### Вимоги
- Android 5.0 (API 21) або вище
- Java 8+
- Gradle 8.1.0

### Структура проекту

```
app/src/main/java/com/angrybirds/game/
├── MainActivity.java      # Головна активність
├── GameView.java          # Ігровий екран та логіка
├── GameObject.java        # Базовий клас для всіх ігрових об'єктів
├── Bird.java              # Клас птаха з фізикою польоту
├── Pig.java               # Клас свинки
├── Block.java             # Клас блоку з фізикою
└── Slingshot.java         # Клас рогатки
```

## Збірка проекту

### Використовуючи Android Studio

1. Відкрийте проект в Android Studio
2. Дочекайтеся синхронізації Gradle
3. Натисніть Run (Shift+F10) або іконку зеленого трикутника
4. Виберіть пристрій або емулятор

### Використовуючи командний рядок

```bash
# Збірка debug версії
./gradlew assembleDebug

# Встановлення на підключений пристрій
./gradlew installDebug

# Збірка release версії (підписана)
./gradlew assembleRelease
```

## Фізичний рух

Гра використовує спрощену фізику:

- **Гравітація**: Постійне прискорення вниз (0.5 пікселів/кадр²)
- **Зіткнення**: Перевірка відстані між круглими об'єктами
- **Відскок**: Втрата 70% енергії при зіткненні з землею
- **Тертя**: Уповільнення руху на 20% при контакті з землею
